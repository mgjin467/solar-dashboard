# 태양광 SMP · REC 대시보드

Vercel + Google Drive 기반. 별도 DB를 사용하지 않습니다.

## 원자료
- 발전량: Google Drive의 `발전 보고서 - 년 ...xls`, `발전 보고서 - 월 ...xls`
- SMP: Google Drive의 `smpDataRt_YYYY.xlsx`
- REC 시세: 한국전력거래소 REC 현물시장 OpenAPI(15099762)
- REC 월별/일별 API 조회 성공값: Google Drive `_REC_MARKET_CACHE` 폴더에 Excel로 누적
- REC 수익화 수기입력: Google Drive `_REC_MARKET_CACHE/REC_수익화_수기입력.xlsx`
- 지역/전국 평균: 한국에너지공단 REcloud 공개페이지를 새로고침 시 재확인

## 주요 기능
- 기간: 전체(2023-01-01~현재), 오늘, 전일, 금주, 전주, 당월, 전월, 분기, 반기, 당해, 전해, 직접선택
- 1/2/3년 전 동기간 복수 비교
- 메인 그래프: 막대=수익/발전량, 라인=SMP/설비이용률/발전시간
- 전국·충북 평균 이용률 및 등가 발전시간 비교
- REC 그래프: 막대=발급량/평가금액, 라인=월별 REC 평균가
- REC 평가금액 단가: 현재 REC 단가 또는 사용자가 선택한 특정일(거래 없으면 직전 거래일)
- API로 조회한 특정일 가격은 Drive `REC_현물시장_일별캐시.xlsx`에 저장하여 재호출 방지
- 누적 예상 REC, 누적 수익화 REC, 남은 REC, 누적 수익화 금액 표시
- 월별 수익화 REC/금액 수기 입력 및 Drive 저장/업데이트
- REC 발급신청 마감 D-Day 및 만료 표시

## 지역 평균 참고
REcloud의 월별/지역별 공개표를 매 새로고침 때 확인합니다. 공급기관이 월별/지역별 최신 연도를 아직 공개하지 않은 경우에는 가장 최근 공개 연도 또는 코드 내 공식 공개 fallback을 사용하며, 화면에 기준연도를 표시합니다. 전국 최신 태양광 평균은 REcloud 메인 현황의 최신 분기값을 별도로 표시합니다.

## 추가 기능: 분기 집계 / REC 집계 연동 / 최고·최저 마커

- 상단 `집계`에 `분기`가 추가됩니다.
- 메인 발전 그래프는 시간/일/월/분기/년 단위로 집계할 수 있습니다.
- REC 그래프는 상단 집계 선택을 따라 다음처럼 자동 집계됩니다.
  - `년` 선택 → REC 연간 집계
  - `분기` 선택 → REC 분기 집계
  - `시간/일/월` 선택 → REC 월간 집계
- REC 발급량(또는 평가금액)은 기간 합계로 막대에 표시합니다.
- REC 단가는 분기/년 집계 시 해당 기간에 존재하는 월별 REC 평균가의 산술평균을 라인으로 표시합니다.
- `최고점`, `최저점` 버튼을 각각 켜고 끌 수 있으며 메인 그래프와 REC 그래프의 각 표시 계열에 마커가 추가됩니다.
- 데이터가 없는 미래 구간의 0값은 최고/최저 마커 계산에서 제외합니다.


## 최고·최저 마커 표시 방식
- 최고점/최저점은 그래프 위에 작은 X 마커만 표시합니다.
- 값/구간/계열명은 마커에 마우스를 올리거나 모바일에서 터치했을 때 툴팁(호버 팝업)으로 표시됩니다.
- 기존처럼 그래프 위에 큰 핀/값 라벨을 직접 표시하지 않습니다.

## REC 수익화 거래내역 방식

월별 발전표의 수익화 REC/금액 입력칸은 제거했습니다. 실제 REC를 판매하거나 정산한 시점마다 별도 `REC 수익화 거래내역` 박스에서 아래 항목을 저장합니다.

- 수익화 일자
- 수익화 REC 수량
- 수익화 금액
- 비고

저장한 거래는 Google Drive `_REC_MARKET_CACHE/REC_수익화_수기입력.xlsx`에 누적되며, 기존 거래의 `수정` 버튼을 눌러 업데이트할 수 있습니다. 월별 REC 표에는 거래 입력칸 대신 해당 월 말까지의 누적 수익화 REC, 누적 수익화 금액, 남은 REC를 계산해 표시합니다.

## REC 공급전력량 기준 (중요)

REC는 발전보고서의 전체 발전량이 아니라 RPS가 인정한 **공급전력량**으로 산정합니다.

```text
REC 산정량 = 공급전력량(kWh) / 1,000 × 가중치
```

공급인증서는 소수점 이하가 이월되므로 실제 발급량은 RPS 실적이 가장 정확합니다.

이 버전은 Google Drive에서 RPS 시스템의 `수수료 납부 및 REC 발급` 등에서 내려받은 Excel을 헤더 기반으로 찾아 다음 열을 자동 인식합니다.

- 발전년월
- 공급전력량
- REC 발급량 (있으면 실제 발급량 우선)
- 신청기한
- 설비코드

파일명은 고정하지 않아도 됩니다. `발전년월 + 공급전력량` 헤더가 있으면 인식합니다. 기존 발전보고서, SMP 파일, REC 시세/수익화 캐시는 자동 제외됩니다.

RPS 실적 Excel이 Drive에 없으면 화면의 `REC 공급량 추정비율`을 사용합니다. 현재 기본값은 사용자가 제공한 RPS 화면의 2026-04~08월 자료에서 전체 발전량 대비 공급전력량이 약 50%로 확인되어 50%로 설정되어 있습니다. 이 값은 추정치이며 실제 RPS 실적 Excel이 있으면 자동으로 실적값이 우선합니다.


## 모바일 REC 그래프 폭 개선
모바일에서 REC 그래프의 오른쪽 축을 위해 과도하게 비워두던 여백을 제거하고 `containLabel` 기준으로 최소 여백만 사용합니다. 그래프 컨테이너도 카드 전체 폭을 사용하도록 강제했습니다.

## 최고/최저 마커 위치 보정
여러 연도의 월 집계처럼 X축에 `01월`, `02월` 등의 같은 라벨이 반복될 때 마커가 같은 이름의 다른 연도 위치에 붙는 문제가 있었습니다. 마커 좌표를 카테고리 문자열이 아니라 실제 데이터 인덱스로 지정하도록 수정해 최고/최저 X 마커가 해당 막대/라인의 정확한 시점에 표시됩니다.


## REC 소수점 이월 계산 규칙

REC 예상 발급량은 월별로 아래 순서로 계산합니다.

1. `당월 산정 REC = 공급전력량(kWh) / 1000 × 가중치`
2. 산정 REC는 소수점 셋째 자리까지 유지하고 **소수점 넷째 자리 이하는 절사**합니다.
3. `발급가능 REC = 전월 이월 REC + 당월 산정 REC`
4. 발급가능 REC의 정수 부분만 당월 발급량으로 계산합니다.
5. 1 REC 미만 소수 부분은 다음 달로 자동 이월합니다.
6. Drive에 RPS 실제 발급량이 있으면 실제 발급량을 최종 우선 사용합니다.

대시보드 REC 표에 `기초 이월 REC`와 `기말 이월 REC`를 함께 표시합니다.

## REC 단가축 범위

REC 그래프의 오른쪽 `원/REC` 축은 기본적으로 조회기간(동기간 비교 포함)에 실제 존재하는 REC 평균가를 기준으로 자동 계산합니다.

- 자동 최소값 = 조회 최저 REC 단가 × 0.9 후 100원 단위 내림
- 자동 최대값 = 조회 최고 REC 단가 × 1.1 후 100원 단위 올림
- 예: 최고가 71,800원 → 71,800 × 1.1 = 78,980원 → 축 최대 79,000원
- `직접 설정`을 선택하면 최소/최대 축 값을 사용자가 입력할 수 있습니다.
- 직접 설정값은 브라우저 localStorage에 저장됩니다.


## 계절 집계
- 봄: 3~5월
- 여름: 6~8월
- 가을: 9~11월
- 겨울: 12~2월
- 겨울은 1~2월이 속하는 해 기준으로 표시합니다. 예: 2025-12 ~ 2026-02 = `2026년 겨울`.
- 메인 발전/SMP/효율 그래프와 REC 그래프·표 모두 상단 `계절` 집계를 따릅니다.

### 계절연도 기간 버튼

기간 선택에는 일반 회계연도와 별도로 계절연도 버튼이 있습니다.

- `당해(계절)` : 전년도 12월 1일 ~ 당해 11월 30일
  - 예: 2026년 기준 `2025-12-01 ~ 2026-11-30`
- `전해(계절)` : 전전년도 12월 1일 ~ 전년도 11월 30일
  - 예: 2026년 기준 `2024-12-01 ~ 2025-11-30`

계절은 기상학적 기준으로 묶습니다.

- 겨울: 12~2월 (12월은 다음 해의 겨울로 표시, 예: 2025-12~2026-02 = `2026년 겨울`)
- 봄: 3~5월
- 여름: 6~8월
- 가을: 9~11월

이 버튼은 **조회 기간만 변경**하며 현재 선택한 집계 방식은 유지합니다. 따라서 `당해(계절)` 기간에서 월/분기/계절/년 등 원하는 집계로 볼 수 있습니다.

## REC 단가축 자동 범위
자동 모드에서는 조회된 REC 단가의 최저값과 최고값을 각각 먼저 1,000원 단위로 절사한 뒤 축 여유를 줍니다.

- 최소축 = `floor(최저 REC 단가 / 1,000) × 1,000 - 1,000`
- 최대축 = `floor(최고 REC 단가 / 1,000) × 1,000 + 1,000`
- 예: 최저 68,450원 → 68,000원 → 최소축 67,000원
- 예: 최고 71,800원 → 71,000원 → 최대축 72,000원

최소축은 0원 미만으로 내려가지 않습니다. 직접 설정 모드는 기존대로 사용할 수 있습니다.

## 추가: 일평균 등가시간 및 전국·지역 발전량 비교

- 메인 라인 그래프에 `일평균 등가시간` 선택을 추가했습니다.
- `전국·지역 비교`는 설비이용률, 발전시간, 일평균 등가시간뿐 아니라 막대가 `발전량`일 때도 동작합니다.
- 지역/전국 평균 발전량은 공개 평균 이용률에서 계산한 등가 발전시간을 현재 선택한 설비용량에 곱해 환산합니다.
  - `평균 발전량(kWh) = 선택 설비용량(kW) × 평균 등가 발전시간(h)`
  - `일평균 등가시간(h/일) = 등가 발전시간(h) ÷ 구간 일수`


## 최신 변경사항

- `당해(계절)` 기간: 해당 연도 **3월 1일 ~ 다음해 2월 말일**
- `전해(계절)` 기간: 전년도 **3월 1일 ~ 올해 2월 말일**
- 계절 집계: 봄 3~5월, 여름 6~8월, 가을 9~11월, 겨울 12~2월
- 전국·지역 평균 비교는 설비이용률, 발전시간, 일평균 등가시간뿐 아니라 **발전량**에도 적용
- 평균 발전량 환산식: `선택 설비용량(kW) × 지역/전국 평균 등가 발전시간(h)`

## REC 유효기간·폐기 관리 추가
- 발급된 REC의 실제 발급일을 기준으로 3년 만료일을 계산합니다.
- RPS Excel에 `발급일`, `REC발급일`, `공급인증서발급일` 계열 열이 있으면 자동 인식합니다.
- 발급일이 없는 월은 화면의 `실제 발급일 보정`에서 입력하며 Drive `_REC_MARKET_CACHE/REC_발급일_수기입력.xlsx`에 저장됩니다.
- 기존 `REC_수익화_수기입력.xlsx`는 그대로 사용하며 `거래유형` 컬럼을 추가해 `수익화`와 `폐기`를 함께 관리합니다. 기존 행은 자동으로 `수익화`로 읽습니다.
- 잔량 계산은 발급 REC에서 수익화, 직접 폐기, 유효기간 만료 자동폐기를 차감합니다.
- 만료 임박은 기준일로부터 6개월 미만 남은 유효 잔량입니다.

## 2026-10 REC 발급일/수명주기 UI 정리
- 기본 발급일: 발전월 말일 + 90일
- 기본 만료일: 적용 발급일 + 3년
- 우선순위: 수기 수정 > RPS 실제 발급일 > 기본 계산일
- 발급일은 접힌 '발급일 직접 수정'에서 필요한 경우만 수정
- REC 유효기간 상세 대형 표 제거
- REC 수명주기 요약은 총 발급 / 총 잔여 / 총 수익화(소유권이전完) / 총 폐기 / 6개월 이내 폐기예정 5개만 표시
- 상단 섹션 네비게이션을 fixed로 변경해 스크롤과 모바일 overflow 영향을 받지 않도록 처리
